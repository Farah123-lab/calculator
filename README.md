# Calculator (Python)

A simple calculator that runs in the terminal.

## What it can do
- Add, subtract, multiply, divide
- Shows a clear message if you divide by zero
- Asks again if you type a wrong number

## How to run
1. Install Python 3
2. Open a terminal in this folder
3. Run: `python main.py`

## Example
```
Operation: +
First number: 5
Second number: 3
Result: 8.0
```

## What I practiced
Functions, input checking, try/except, while loops.
